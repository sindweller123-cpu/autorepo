Esquema de metadatos
Estándares Dublin Core (DC) y Learning Object Metadata (LOM) aplicados al repositorio de autobiografías

¿Por qué usamos estos estándares?

Dublin Core (ISO 15836) permite describir cualquier recurso digital de forma universal. LOM (IEEE 1484.12.1) añade campos específicos para recursos educativos. Juntos garantizan que las autobiografías sean fáciles de encontrar, clasificar y reutilizar en otros entornos educativos.
